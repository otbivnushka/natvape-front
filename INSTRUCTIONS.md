# INSTRUCTIONS — Система бонусных баллов

## Обзор

Добавлена система бонусных баллов. Пользователь получает 3% от суммы заказа в виде баллов. Баллы можно тратить на оплату заказов (только целыми числами). Даже при оплате баллами новые баллы начисляются.

**Курс:** 1 балл = 1 денежная единица.

---

## 1. Получение баланса и истории

### `GET /api/bonus`

**Авторизация:** Bearer token

**Пэйлоад:** нет

**Ответ:**

```json
{
  "balance": 4.56,
  "spendable": 4,
  "history": [
    {
      "id": 1,
      "amount": 3.00,
      "type": "accrual",
      "orderId": 15,
      "description": "Начисление за заказ #15",
      "createdAt": "2026-09-26T12:00:00.000Z"
    },
    {
      "id": 2,
      "amount": -2.00,
      "type": "spend",
      "orderId": 14,
      "description": "Оплата заказа #14 баллами",
      "createdAt": "2026-09-25T10:30:00.000Z"
    }
  ]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `balance` | number | Текущий баланс (может быть дробным, напр. `4.56`) |
| `spendable` | number | Сколько баллов можно потратить (целая часть, напр. `4`) |
| `history[].amount` | number | `+` начисление / `−` списание |
| `history[].type` | string | `accrual` / `spend` / `expire` / `admin_adjustment` |
| `history[].orderId` | number \| null | Связанный заказ (если есть) |

## 2. Создание заказа (изменён)

### `POST /api/orders`

**Авторизация:** Bearer token

**Пэйлоад:**

```json
{
  "deliveryMethod": "delivery",
  "addressId": 5,
  "deliveryTime": "14:00-16:00",
  "comment": "Позвонить за час",
  "bonusToUse": 4
}
```

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `deliveryMethod` | string | Да | `"pickup"` или `"delivery"` |
| `addressId` | number | Нет | ID адреса доставки |
| `deliveryTime` | string | Нет | Время доставки |
| `comment` | string | Нет | Комментарий |
| `bonusToUse` | number | Нет | Сколько баллов списать (целое число, по умолчанию `0`) |

**Правила `bonusToUse`:**
- Только целое число (`1`, `2`, `3`...)
- Нельзя превысить `spendable` из `GET /api/bonus`
- Если баллов недостаточно — ошибка `400` с сообщением `"Insufficient bonus balance"`

**Ответ:**

```json
{
  "id": 16,
  "userId": 1,
  "total": 97.00,
  "actualPrice": 97.00,
  "status": "sent",
  "deliveryMethod": "delivery",
  "comment": "Позвонить за час",
  "addressId": 5,
  "deliveryTime": "14:00-16:00",
  "bonusUsed": 4,
  "bonusAccrued": 2.91,
  "createdAt": "2026-09-26T12:00:00.000Z",
  "updatedAt": "2026-09-26T12:00:00.000Z",
  "items": [...],
  "address": {...},
  "user": {...}
}
```

| Новое поле | Тип | Описание |
|---|---|---|
| `bonusUsed` | number | Сколько баллов списано за этот заказ |
| `bonusAccrued` | number | Сколько баллов начислено за этот заказ (3% от итоговой суммы) |

## 5. Ручная корректировка баллов (админ)

### `POST /api/admin/users/:id/bonus`

**Авторизация:** Bearer token (только админ)

**Пэйлоад:**

```json
{
  "amount": 10.00,
  "description": "Бонус за отзыв"
}
```

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `amount` | number | Да | Положительное — начисление, отрицательное — списание |
| `description` | string | Нет | Причина корректировки |

**Ответ:**

```json
{
  "userId": 1,
  "balance": 14.56
}
```

## Логика начисления и списания

### Начисление баллов

```
bonusAccrued = (total - bonusToUse + deliveryFee) * 0.03
```

- Начисляется на всю сумму заказа, включая доставку
- Начисляется даже если заказ полностью оплачен баллами
- Результат может быть дробным (напр. `2.91`)

### Списание баллов

```
finalTotal = total + deliveryFee - bonusToUse
```

- Списываются только целые баллы
- Нельзя списать больше, чем есть на балансе
- Баллы не покрывают доставку (только товары)

### Отмена заказа (админ)

При удалении заказа админом:
- Потраченные баллы возвращаются пользователю
- Начисленные баллы сгорают

---

## Пример сценария

1. Пользователь заказывает товары на 100, доставка 3 → `finalTotal = 103`
2. Начисляется `103 * 0.03 = 3.09` балла
3. Пользователь копит баллы: после нескольких заказов баланс `12.50`
4. Новый заказ на 50, доставка 3 → `subtotal = 53`
5. Пользователь тратит `10` баллов → `finalTotal = 43`
6. Начисляется `43 * 0.03 = 1.29` балла
7. Итоговый баланс: `12.50 - 10 + 1.29 = 3.79`
